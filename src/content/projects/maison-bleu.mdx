## <span id="overview">Overview</span>

Maison bleu is a **clothing storefront and admin dashboard** web app. This webapp allows admin users to upload, manage, and sell inventory. Users can browse products, select variants, manage items in their cart, and place orders. 

The admin dashboard has role-based access, isolating revenue and
inventory analytics to privileged management roles while optimizing staff packing operations. Staff are given explicit instructions for how to fulfill orders.
